# Repair eMolPat

Use repair only for the complete approved suite; never reinstall one analysis program independently.

1. Close all eMolPat analysis programs.
2. Confirm the approved release folder on `K:` is available and unchanged.
3. Run **Installer eMolPat.cmd** from that exact release folder again.
4. Paste the copied command into Python FELLES and wait for verification.
5. Start eMolPat and confirm the suite status is **Klar til bruk**.

If repair fails, stop. Do not delete user settings, reports, or patient files. Send technical support the eMolPat version, failed stage, and `%LOCALAPPDATA%\eMolPat\logs`. The logs are technical and redacted, but they should still be handled through approved support channels.
