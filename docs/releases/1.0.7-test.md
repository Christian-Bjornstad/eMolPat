# eMolPat 1.0.7-test

This prerelease is the workstation-test candidate for the persistent eMolPat
portal on Python FELLES 3.14. It is not approved for routine laboratory use
until the managed-workstation checklist has been completed.

## Highlights

- eMolPat remains open and responsive after an application is launched.
- Every analysis application runs in a separate Python process.
- Hemato contains HemaFrag, IGH Merge, VPM / HTS Tolkning, and MPN Tolkning.
- Solide is ready for future tools but is currently empty.
- STAT shows LVMS-STAT as `Kommer senere`; it is not installed, launched, or
  included in suite health verification in this release.
- Update and repair are blocked while an analysis application is running.

## Installation

1. Download `eMolPat-1.0.7-test-windows.zip` from this prerelease.
2. Verify it against the published `.sha256` file.
3. Extract the complete ZIP to a normal local folder.
4. Run `Installer eMolPat - Manuell FELLES.cmd`.
5. Open Python FELLES through the workstation's approved route, paste the
   copied command, press Enter, and wait for verification to complete.
6. Start the portal with `Start eMolPat - Manuell FELLES.cmd`.
