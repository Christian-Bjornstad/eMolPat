# eMolPat 1.2.0 test release

eMolPat 1.2.0 adds MolKey 0.2.0 as the suite's sixth standalone application.
MolKey has its own portal tab because it is a shared tool rather than a Hemato,
Solide, or Statistikk application. The former STAT tab is now labelled
Statistikk.

## Included change

- MolKey is pinned to commit `a01b5df13fc05bb0d2013d730405be85f25addf4`.
- eMolPat starts MolKey through the zero-argument entry point
  `molkey.__main__:main` in the existing separate-process manager.
- The portal remains open while MolKey runs and prevents duplicate launches in
  the same way as the other applications.
- The offline package contains the eMolPat portal, six application wheels, and
  all locked Python 3.14 Windows dependencies.
- MolKey remains responsible for its registry, permanent pseudonyms,
  secure-drive SQLite database, settings, and environment configuration.
  eMolPat does not read or store that information.

## Validation before laboratory use

The automated eMolPat tests, component tests, manifest consistency check,
offline build, installed-suite smoke test, and archive verification must pass
before publication. A clean Python FELLES/Citrix workstation test must then
confirm installation, startup, secure-drive access, duplicate-launch handling,
and normal shutdown.

This is a test release and is not approved for routine laboratory use until the
managed-workstation and laboratory sign-off checklist is complete.
