# eMolPat 1.1.0

This release adds LVMS-STAT 2.0.0 as the fifth standalone application in the
offline eMolPat suite.

## Highlights

- `LVMS Statistikk` is available under the `STAT` tab.
- LVMS-STAT starts through `lvms_stat.portal:main` in its own Python process.
- eMolPat remains open, prevents duplicate launches, and observes process exit.
- LVMS-STAT continues to own authentication, report retrieval, Local AppData
  settings, and K-disk input/output.
- The offline release contains eMolPat and five pinned component wheels.

## Installation

1. Download `eMolPat-1.1.0-windows.zip` and its `.sha256` sidecar.
2. Verify the checksum and extract the complete ZIP.
3. Run `Installer eMolPat - Manuell FELLES.cmd`.
4. Paste the copied command into Python FELLES and wait for verification.
5. Start the portal with `Start eMolPat - Manuell FELLES.cmd`.
