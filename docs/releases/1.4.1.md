# eMolPat 1.4.1 candidate

The portal now uses the current VPM, MolKey and Solide icons. All nine icons are
copied from the exact application commits bundled with the suite, and missing or
stale icon files now block release builds, including omissions inside the wheel.

**Om eMolPat** shows only **Utviklet av Christian Bjørnstad**.

All remote component branch heads were checked again. The existing component
pins already contain the latest applicable implementations, including MolStat;
this patch does not change application runtime code or dependencies. The
[icon audit](../validation/2026-10-30-icon-refresh.md) records the source commits
and verification. The nine-app catalog and offline installation remain as in
[1.4.0](1.4.0.md).

This candidate uses suite version 1.4.1 and portal distribution 0.4.1. The
published 1.4.0 assets remain unchanged.
