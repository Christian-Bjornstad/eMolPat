# eMolPat 1.2.1 test release

eMolPat 1.2.1 updates LVMS Statistikk to 2.0.1 and fixes false preflight
failures caused by operator CMD files placed beside the verified release.

## Included changes

- LVMS-STAT is pinned to immutable commit
  `72294225760b73d803edc66baaed8a3c3cb866f0`.
- The Windows archive contains only `Installer eMolPat.cmd` and
  `Start eMolPat.cmd` as operator launchers.
- The complete verified offline payload lives under `suite`.
- Extra files outside `suite` cannot invalidate the signed payload.
- Obsolete manual, clean-import, and diagnostic launchers are removed.

## Installation

Download `eMolPat-1.2.1-windows.zip` and its SHA-256 sidecar from GitHub
Releases. Verify the checksum, extract the complete ZIP, and run
`Installer eMolPat.cmd`. Paste the copied command into Python FELLES and wait
for the verified installation to finish. Use `Start eMolPat.cmd` for later
launches.

This is a test release and still requires final installation and application
launch validation on a Sykehuspartner-managed Python FELLES/Citrix workstation.
