# eMolPat 1.3.0 candidate

This candidate replaces LVMS-STAT with MolStat and adds Solide. Its seven
applications are HemaFrag Diagnostics, IGH Merge, VPM / HTS Tolkning, MPN
Tolkning, MolStat, MolKey, and Solide. Each runs in a separate process while the
portal remains responsive. The source audit and exact commits are recorded in
[the repository audit](../validation/2026-10-20-repository-audit.md).

MolStat opens its GUI with the same settings location used by its standalone
launcher: `%LOCALAPPDATA%/MolStat/settings.json`. Its own setup interface handles
missing settings. eMolPat neither reads nor rewrites those settings. Existing
LVMS-STAT configuration is not automatically converted to MolStat configuration.

LVMS-STAT is absent from the current catalog, component contract, and release
payload. Historical release documentation and rollback records remain available.
Installing this candidate does not delete an older application's local data.

The offline payload targets CPython 3.14 on 64-bit Windows. Broader source
compatibility, future-Python checks, and the steps for validating a new offline
target are described in [the Python policy](../operations/python-support.md).

Startup arguments are isolated from the portal runner. Repair can be retried
after another application has closed; a blocked repair no longer prevents
closing the portal. Running application cards retain their state when health is
refreshed. Closing the portal also closes its status dialog. Unit and About
pages derive from the seven-app manifest, with cards reflowing in smaller windows.

Offline assembly checks the complete dependency closure, requested extras,
Windows environment markers, Python metadata, and wheel tags. Manual release
dispatch checks out and verifies the selected tag.

## Validation

- 178 portal tests pass independently on Windows Python 3.12, 3.14 and 3.15.
- All seven component suites pass on Windows Python 3.14: 4,399 passed and
  7 existing conditional skips. MolStat includes the test-only portability fix
  in [PR #7](https://github.com/Christian-Bjornstad/MolStat/pull/7).
- Lint passes on a clean export of the tracked source. Portal wheel and source
  distribution builds pass.
- All 85 hash-locked dependency wheels install offline into a fresh Python 3.14
  environment. All eight application wheels install, `pip check` passes, and
  installed-suite validation resolves all seven GUI launchers.
- Each installed application's actual main window opens in an isolated headless
  Qt process and exits successfully after a timer requests shutdown. Settings
  and temporary output are isolated from the user's real app configuration.
- Full dependency/ABI validation, release integrity, and ZIP/checksum generation
  pass. The ZIP contains two operator launchers and the protected `suite` payload.
- The next-Python advisory currently reports that GitHub's Windows runner has no
  Python 3.16 development build. It retries weekly; this is not a claim of 3.16
  compatibility.
