# eMolPat 1.0.4 Python 3.14 test prerelease

This release fixes the first Python FELLES 3.14 workstation update test. It
force-replaces all five local application wheels, records the matching suite
identity, and closes the portal after a successful in-app update so it can be
started again with the newly installed code.

## Install over 1.0.3

1. Download and extract `eMolPat-1.0.4-python314-test-windows.zip`.
2. Run `Installer eMolPat - Manuell FELLES.cmd` from the extracted release root.
3. Open Python FELLES 3.14, paste, and wait for the verified success message.
4. Run `Start eMolPat - Manuell FELLES.cmd` and paste in Python FELLES again.
5. The portal should show `Klar til bruk` and enable all four applications.

The update path was verified by installing this release over an existing
`1.0.3-python314-test` temporary user profile. The result contained
`emolpat==0.1.1`, suite record `1.0.4-python314-test`, and successful imports of
all four analysis applications.
