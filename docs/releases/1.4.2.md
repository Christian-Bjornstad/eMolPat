# eMolPat 1.4.2

Installation now resolves the release from the installer file itself, clears
cached eMolPat imports in reused Python FELLES prompts, and displays the error
directly when bootstrap fails. Start refuses an older installed portal instead
of opening it silently. Close Python FELLES before installing from a new folder.

Current application PRs have been merged into their default branches:
HemaFrag #10, IGH #2, Archer-prosess #13, MolStat #9 then #8, and Solide #2.
MolKey #3 was already merged. All nine pins now refer to the repository defaults.
All icons were resynchronized from these exact Git objects. Archer, Solide and
MolKey retain their updated icons, verified by the release build gate.

The workstation failure could not be reproduced from the unavailable user log;
these fixes cover identified stale-folder and cached-import faults. Python
FELLES must provide Python 3.14 for the bundled native Windows dependencies.
