# eMolPat 1.2.2 test release

eMolPat 1.2.2 is the publishable follow-up to 1.2.1. It keeps the isolated
verified payload and updates the LVMS-STAT 2.0.1 pin with a portable Windows
path assertion required by the GitHub release gate.

## Included changes

- LVMS-STAT is pinned to immutable commit
  `eb07f3f40535117c123d140ab9674d4a87191292`.
- The Windows archive contains only `Installer eMolPat.cmd` and
  `Start eMolPat.cmd` as operator launchers.
- The complete verified offline payload lives under `suite`.
- Extra files outside `suite` cannot invalidate the signed payload.

Download `eMolPat-1.2.2-windows.zip` and its SHA-256 sidecar from GitHub
Releases. Extract the complete ZIP and run `Installer eMolPat.cmd`.

This test release still requires final installation and application launch
validation on a Sykehuspartner-managed Python FELLES/Citrix workstation.
