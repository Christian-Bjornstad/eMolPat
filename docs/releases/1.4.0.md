# eMolPat 1.4.0 candidate

The single searchable catalog contains HemaFrag, IGH Merge, VPM / HTS Tolkning,
MPN Tolkning, MolStat, MolKey, DRAGEN, Solide and Qiaxcel. Cards show icons,
names, versions, status and launch actions, with no explanatory text. About and
system status remain available. The nine cards fit in three rows at 1600×800.

Component commits come from the current active implementation branches, rather
than assuming default branches contain the latest work. The complete branch
inventory, ancestry comparisons and PR links are in the
[component audit](../validation/2026-10-30-component-audit.md).
Historical research branches with many missing newer commits are recorded
separately; they have not been silently merged into clinical applications.

DRAGEN uses the `abl1-dragon` distribution and Qiaxcel uses
`qiaxcel-fortynning`. Their installed GUI entry points and resources are included
in the ten-wheel suite. The Windows CPython 3.14 offline dependency set includes
Pillow 13, Qiaxcel's pinned PDF reader dependencies and HemaFrag's native kernel
0.1.3. The builder validates target compatibility and complete dependency closure
before hashing the payload.

MolStat retains the latest timeline branch and incorporates the earlier Python
3.14 test portability fixes in a separate child branch. Its production source
is unchanged by those test fixes; both the integration and fix PRs are linked in
the audit. Open upstream PRs remain reviewable and are not represented as merged.

The release test command now also installs a component's declared
`requirements-dev.txt` and HemaFrag's shipped native wheel. This ensures the
packaging/native tests run with their actual required tools.

This is a development candidate. The published 1.3.0 release remains immutable.
Operational acceptance follows the [workstation checklist](../validation/release-checklist.md).
