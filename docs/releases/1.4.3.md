# eMolPat 1.4.3

MolStat pathology updates start on the last confirmed archive date, including
that date. The first load starts in January 2024 and tries 12 months at a time.
After transient LVMS failures, it falls back to 6, 3, then 1 month at a time.
Confirmed periods are saved as the load runs so it can resume after an
interruption. [MolStat 6f86cb5](https://github.com/Christian-Bjornstad/MolStat/commit/6f86cb50b0bf7775451b6881ea07f76eec98701b)

Download and extract the Windows ZIP, then run **Installer eMolPat.cmd** using
the established Python FELLES installation procedure.
