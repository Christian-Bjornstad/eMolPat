# eMolPat 1.0.3 Python 3.14 test prerelease

`v1.0.3-python314-test` is an immutable test release for Python FELLES 3.14 on
64-bit Windows. It contains the eMolPat portal, all four analysis applications,
and every required dependency. Installation is offline and per user.

## Download

Download both assets from the GitHub prerelease:

- `eMolPat-1.0.3-python314-test-windows.zip`
- `eMolPat-1.0.3-python314-test-windows.zip.sha256`

Do not use GitHub's source-code ZIP because it does not contain the applications
or dependency wheelhouse.

## Work-computer test

1. Extract the complete ZIP to a writable folder.
2. Run `Installer eMolPat - Manuell FELLES.cmd`.
3. Open Python FELLES 3.14 through the workstation's normal approved method.
4. Paste the copied command, press Enter, and wait for the success message.
5. Run `Start eMolPat - Manuell FELLES.cmd`.
6. Open Python FELLES 3.14 again, paste the copied command, and press Enter.
7. Confirm eMolPat opens and launches each of the four tools.
8. If startup fails, run `Start eMolPat - Diagnose.cmd` and return its text.

The first install can take several minutes because 79 dependency wheels and five
application wheels are installed and verified in the user's Python 3.14 site.
